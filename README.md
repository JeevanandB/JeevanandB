## Featured project

### [Match-Day Demand Forecasting & SKU Order Planner](https://github.com/JeevanandB/LaneEndLocal-matchday-forecast) · [Live dashboard](https://jeevanandb.github.io/LaneEndLocal-matchday-forecast/)

How much should a corner shop next to Bramall Lane order for match day? The project uses Sheffield United's real home fixtures (92 matches, 2023–2026) and crowd sizes as the demand driver. The store data is simulated; the fixtures are real.

- Cleaned 71,000+ product-day records (duplicates, prices logged in pence, till outages rebuilt from stock movement) and built a star-schema Power BI model with DAX measures across four report pages.
- Cut match-day forecast error (WAPE) from 52.4% to 39.8% against the store's 28-day-average ordering rule, on an out-of-sample test of four home matches.
- Turned forecasts into SKU order recommendations: flagged 22 of 47 lines for the next match and identified products whose true demand was hidden by sell-outs.
